Automating job discovery and ranking

I designed a personal job-discovery workflow and developed it with coding agents. It brings postings from multiple APIs into a common schema, removes duplicates and ranks opportunities using local embeddings.

Ranked digest A personal tool for reviewing opportunities before deciding where to apply.
Fetch→Normalize→Deduplicate→Rank→Human review

Problem

Roles appear across different boards with inconsistent fields, duplicates and changing availability. Reviewing each source separately made it difficult to maintain a consistent shortlist.

Decision

Use explicit rules for normalization and duplicate detection, local embeddings for relevance ranking, and a digest for human review. Keep the original posting data available alongside the normalized records.

My contribution

I directed the workflow design and AI-assisted implementation using Python, SQLite and API integrations. I defined the stage boundaries and failure handling: if a required stage fails, dependent work stops.

Outcome

The system produces a ranked digest for review. It is a personal tool with a human review step. Application submission and hiring outcomes are outside this case study.

Workflow and failure handling

Each stage consumes the previous stage’s output. Required-stage failures stop dependent processing so an incomplete fetch cannot silently produce an apparently complete digest.

Fetch → Normalize → Deduplicate → Rank → Review
Required stage failure → Stop dependent stages
