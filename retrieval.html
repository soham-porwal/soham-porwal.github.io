Evaluating source diversity in AI search

I tested whether source caps and diversity selection improved search over a personal note collection. The change returned a broader mix of sources but retrieved fewer relevant notes. I reverted to plain vector search.

0.4764 → 0.3731 Recall among the first six results fell under the diversity change, so the change was reverted.

Problem

A personal knowledge corpus contained many more notes from some sources than others. Those sources could dominate retrieval even when a broader result set seemed desirable.

Decision

Test source caps and diversity selection against plain vector search, with acceptance criteria fixed before the comparison. Better source balance alone would not justify worse retrieval.

My contribution

I directed the retrieval and evaluation workflow using coding agents, defined the comparison and interpreted the results. The evaluation records the query set, configurations and index fingerprints so both versions can be compared against the same inputs.

Outcome

Source diversity improved, but recall declined from 0.4764 to 0.3731. The change failed the acceptance criteria and was reverted. A later configuration sweep suggested a candidate for testing on a fresh query set; it was not adopted on the strength of that sweep.

Method: recall measures how much of the reference set appears in the first six results. Reference sets were derived programmatically, including text matching, rather than fully labeled by people. The result applies to this corpus and query set.

Recompute the recorded result

The download contains anonymous paired recall scores and a Python scorer that reproduces the means shown above. Queries and corpus content remain private, so this reproduces the arithmetic, not the original retrieval run or its relevance judgments.

python retrieval_eval/scorer.py
python retrieval_eval/scorer.py --synthetic

Extract the ZIP and run these commands from its top-level folder. The second command uses synthetic scores to illustrate the calculation separately from the recorded result.
